1. Алгоритм и блок-схема

Алгоритм:

1. Начало.
2. Объявить целочисленную переменную n для хранения введенного числа.
3. Объявить вещественную переменную product (для накопления произведения) и инициализировать её значением 1.0.
4. Запросить у пользователя ввод целого числа N.
5. Организовать цикл for от i = 1 до N включительно (блок «Повторение»).
6. Внутри цикла вычислить текущий множитель: term = 1.0 + i / 10.0 (формируем числа 1.1, 1.2, 1.3 и т.д.).
7. Умножить текущее накопленное произведение на этот множитель: product = product * term.
8. Вывести на экран итоговое значение product.
9. Конец.

#include <stdio.h>

int main() {
    int n;
    printf("Введите целое N: ");
    scanf("%d", &n);

    double product = 1.0;
    for (int i = 1; i <= n; i++) {
        double term = 1.0 + i / 10.0; // Формируем 1.1, 1.2 и т.д.
        product *= term;
    }

    printf("Произведение ряда: %lf\n", product);
    return 0;
}
